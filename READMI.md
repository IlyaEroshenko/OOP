Система управления товарами и категориями
Простейшая реализация системы для работы с товарами и категориями, включающая загрузку данных из JSON‑файла.

Описание
Проект состоит из двух основных классов:

Product — представляет товар с атрибутами: название, описание, цена, количество в наличии.

Category — представляет категорию товаров с атрибутами: название, описание и список товаров.

Основная функция load_data_from_json() загружает данные о категориях и товарах из JSON‑файла, 
обрабатывает возможные ошибки и возвращает список объектов Category.

Установка и запуск
Убедитесь, что у вас установлен Python (версия 3.7+).

Создайте файл data/products.json

Запустите ваш скрипт, импортировав необходимые компоненты.

Использование
Пример JSON‑файла (data/products.json)
json
{
  "categories": [
    {
      "name": "Электроника",
      "description": "Электронные устройства",
      "products": [
        {
          "name": "Смартфон",
          "description": "Современный смартфон",
          "price": 29999.99,
          "quantity": 10
        }
      ]
    }
  ]
}
Пример кода для загрузки данных
python
from your_module import load_data_from_json

categories = load_data_from_json("data/products.json")

for category in categories:
    print(f"Категория: {category.name}")
    for product in category.products:
        print(f"  Товар: {product.name}, Цена: {product.price}, Количество: {product.quantity}")
Функции и их назначение
Product.__init__()
Инициализирует объект товара с заданными параметрами.

Category.__init__()
Инициализирует объект категории с названием, описанием и пустым списком товаров.

load_data_from_json(filename)
Загружает данные из указанного JSON‑файла:

Обрабатывает ошибки: отсутствие файла, некорректный JSON, другие исключения.

Возвращает список объектов Category или пустой список в случае ошибки.

Обработка ошибок
Функция load_data_from_json() обрабатывает следующие типы ошибок:

FileNotFoundError — файл не найден.

json.JSONDecodeError — ошибка при декодировании JSON.

Общие исключения (Exception) — любые другие непредвиденные ошибки.

В случае ошибки выводится сообщение и возвращается пустой список.
