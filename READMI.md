
## Описание проекта

Это приложение для управления товарами и категориями в интернет‑магазине. Реализовано на Python с использованием 
ООП‑подхода.
Проект позволяет:

- создавать товары (`Product`) с указанием названия, описания, цены и количества;
- группировать товары в категории (`Category`);
- добавлять/удалять товары из категорий;
- загружать данные из JSON‑файла;
- получать список товаров в удобном формате.

## Структура проекта

```
src/
├── oop_work.py      # Основные классы (Product, Category) и функция загрузки данных
└── main.py         # Пример использования классов
data/
└── products.json    # Пример JSON‑файла с данными (опционально)
```

## Основные классы

### `Product`
Представляет товар.

**Атрибуты:**
- `name` — название;
- `description` — описание;
- `price` — цена (валидируется: должна быть числом > 0);
- `quantity` — количество в наличии.

**Методы:**
- `__init__()` — инициализация товара;
- `@property price` / `@price.setter` — геттер и сеттер для цены с валидацией;
- `new_product()` — фабричный метод для создания товара из словаря.

### `Category`
Представляет категорию товаров.

**Атрибуты:**
- `name` — название категории;
- `description` — описание;
- `__products` — приватный список товаров (доступ через `@property`).

**Методы:**
- `__init__()` — инициализация категории;
- `@property products` — получение списка товаров в виде строк;
- `add_product()` — добавление товара в категорию;
- `product_count()` — количество товаров в категории;
- `get_products()` — список товаров в формате строк.


## Функции

### `load_data_from_json(filename)`
Загружает данные из JSON‑файла и создаёт список категорий с товарами.

**Параметры:**
- `filename` — путь к JSON‑файлу (по умолчанию `data/products.json`).


**Возвращает:**
- Список объектов `Category`.

**Обработка ошибок:**
- `FileNotFoundError` — файл не найден;
- `JSONDecodeError` — ошибка формата JSON;
- Пропуск некорректных товаров/категорий с логированием.

```json

    {

      "description": "Мобильные устройства",
      "products": [

          "quantity": 5

        {
          "name": "Iphone 15",
          "description": "512GB, Gray space",
          "price": 210000.0,
          "quantity": 8
        }

```

## Как запустить

1. Установите Python (рекомендуется версия 3.8+).
2. Создайте виртуальное окружение (опционально):
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/macOS
   venv\\Scripts\\activate    # Windows
   ```
3. Запустите `main.py`:
   ```bash
   python src/main.py
   ```

## Примеры использования

**Создание товара:**

```python
product = Product("Название", "Описание", 1000.0, 10)
```

**Создание категории и добавление товара:**
class Category:
pass

```python
category = Category("Категория", "Описание")
category.add_product(product)
```

**Загрузка данных из JSON:**
```python
categories = load_data_from_json("data/products.json")
```

## Логирование

Приложение использует модуль `logging` для вывода предупреждений и ошибок:
- Предупреждения о пропущенных товарах/категориях;
- Ошибки при чтении файла.


Уровень логирования: `INFO` (можно изменить в `logging.basicConfig()`).
